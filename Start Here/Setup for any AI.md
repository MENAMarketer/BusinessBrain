# Setup for any AI

Works with Grok, Gemini, Copilot or any assistant that lets you attach a file.

1. Start a new chat.
2. Attach **Business Brain.md**.
3. If you have them, also attach your **Business File** and **Voice File**.
4. Type **run brain**.

Next time, do the same. The files carry the memory, so nothing is lost between chats.

If the assistant has a way to keep files together (Projects, Gems, custom agents), put the files there once and just type **run brain** in each new chat.
