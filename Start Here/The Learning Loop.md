# The Learning Loop

Build. Use. Learn. Improve.

Nobody gets their system right on day one. It gets better every time you use it, but only if you close the loop.

## The loop

1. **Ask** the Copywriter for something real.
2. **Tell it what you would change.** Be specific: "Too formal." "I would never say 'excited to announce'." "Lead with the story."
3. **It sorts your feedback.** A one off fix goes in the draft. A habit goes in your Voice File. A new fact goes in your Business File. If it is not sure, it asks.
4. **Save the updated file.** It gives you the whole file. Save it over the old one in your folder and in your project. Ten seconds.

Skip step four and the next draft makes the same mistake. That ten second step is how the system learns.

## Check how it is learning

Every file has a **Changes log** at the bottom. Read it once a month. It shows what the system has learned about you, and where it still gets you wrong.

## When to start again

If a file has grown long and contradicts itself, ask the agent: "Rewrite my Voice File from scratch, keeping everything that is still true." Then check it line by line.
