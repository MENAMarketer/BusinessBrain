# Setup for ChatGPT

About five minutes. Do this on a laptop, signed in to chatgpt.com.

1. Click **Projects** in the left sidebar, then **New project**.
2. Name it after your business, for example "Harbour & Co AI System".
3. Open the project's **instructions** and paste in everything below the line in *Project Instructions.md*. Replace [Business name] with yours.
4. Open the project's **files** and add the four agent files from the *1 Agents* folder (not the New Agent Template). Do not add the blank templates.
5. Start a new chat inside the project and type **/research** followed by your website address.

## As you go

- When an agent gives you a **Business File** or **Voice File**, save it in your *My AI System* folder (*2 My Business* or *3 My Voice*). Before your next chat, add it to the project's files.
- When an agent gives you an **updated** file, remove the old one from the project's files and add the new one.
- Start a fresh chat inside the project for each new piece of work. The files carry the memory, so nothing is lost.

## If it cannot read your website

Some assistants can read websites and some cannot, depending on your plan and settings. If it says it cannot, copy the text of your home page and about page and paste it in. The result is the same.
